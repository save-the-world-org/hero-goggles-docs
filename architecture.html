Architecture

A beacon, a phone, an API, a static web app and a pair of glasses.

The iPhone and the beacon

Each beacon is a Qorvo DWM3001CDK: Nordic's nRF52833 for Bluetooth LE and Qorvo's DW3110 for UWB. It runs Qorvo's prebuilt Nearby Interaction firmware (QANI). The phone finds it over Bluetooth, then measures it over UWB with Apple's Nearby Interaction. hero-goggles-ios (hero-goggles-ios/App) holds the seek (hero-goggles-ios/App/Seeker.swift), the lens (hero-goggles-ios/App/GlassesCard.swift) and the link to the API (hero-goggles-ios/App/InfluenceLink.swift). Board notes, calibration and the rules that cost something are in beacon-firmware/docs.

influence-api

One file, influence-api/server.js, on Node 22 with OpenTelemetry its only dependency. It keeps the registry of influencers and beacons, takes readings and each phone's GPS and heading, holds each seeker's target, raises distance alerts, and streams everything to the map as Server-Sent Events. The same actions are MCP tools. With ES_URL set, the registry, the targets and the alerts are written to Elasticsearch and survive a restart; readings stay in memory, since the phone resends twice a second.

Alerts, per seeker and only for the target's beacon: closer below 50, 30, 20, 10 and 5 ft, found at 3 ft, farther with a 1.5 ft band so jitter never flaps, and lost after 10 s without a reading. At most one every 4 s per seeker. Details in influence-api/README.md.

hero-goggles, the web app

Two pages from one Vite build. / is the glasses app: 600 x 600 on an additive display, so black is see-through and the app draws light on black; input is arrow keys and Enter from the touchpad and Neural Band; the first load stays under 300 KB and 15 requests, so React runs on preact/compat. /live/ is the map for phones and laptops, the only page that loads MapLibre (hero-goggles/src/live).

The live map

The map draws the Salt Palace's outline and a minimap, each beacon at its estimated position, the seekers with their heading, and a banner for each alert. It reads /api/state once, then follows /api/events. Its Integrations panel reads /api/integrations every 5 s and shows Skyhook Radar, Dash0, Elasticsearch and Gitar by Sonar; while the API has none of them, nothing shows and nothing fails (hero-goggles/src/live/Integrations.jsx).

Where it runs

On Infrared's hosted plane, in the org save-the-world-org: one Product, Hero Goggles, whose umbrella chart deploys the web app and influence-api together. The web app is public at hero-goggles.darkshift.cloud, the API at influence-api.darkshift.cloud. See Built on Infrared.
