hero-goggles

The Meta Ray-Ban Display web app (a list, a map and Find, driven by the Neural Band) and, at /live/, the live map of the Salt Palace: the beacons, Skyhook Radar's alerts, the registry, influencer pages, Find by voice, WebMCP, and the integrations with each sponsor's logo.

Sourcegithub.com/save-the-world-org/hero-goggles
Runs athero-goggles.darkshift.cloud and /live/, an Infrared Product on the hosted plane
Built withVite, React on preact/compat, MapLibre; built by Paketo buildpacks and served by nginx
Run itnpm install, npm run dev (http://localhost:5173), npm run build
Checknpm run build; Gitar by Sonar reviews each pull request against .gitar/rules/instrumentation.md
Read moreQuick start, Skyhook Radar, Gitar by Sonar

influence-api

The API behind Hero Goggles: the beacon and influencer registry, live readings from the phone, who each seeker is looking for, distance alerts, a live event stream for the map, search over KubeCon's sessions and speakers, and the same actions as MCP tools (find_influencer, where_is, list_influencers, search).

Sourcegithub.com/save-the-world-org/influence-api
Runs atinfluence-api.darkshift.cloud; MCP at https://influence-api.darkshift.cloud/mcp
Built withOne file, server.js, on Node 22; OpenTelemetry to Dash0; Elasticsearch when ES_URL is set
Run itnpm start (http://localhost:8080); claude mcp add --transport http influence https://influence-api.darkshift.cloud/mcp
Checknpm test: the server as real processes, against a fake Elasticsearch and with none
Read moreArchitecture, Elasticsearch, Dash0, MCP

hero-goggles-ios

The iPhone app on Meta's Wearables Device Access Toolkit: it draws on the Ray-Ban Display glasses, takes Neural Band presses, and seeks a UWB beacon (“Hero Finder”), with the distance and the way on the phone, in the lens and aloud. Each reading goes to influence-api.

Sourcegithub.com/save-the-world-org/hero-goggles-ios
Runs atYour own iPhone, signed with your own Apple Developer team; or a simulator with Meta's simulated glasses
Built withSwift, SwiftUI, Nearby Interaction, Meta's Wearables Device Access Toolkit 1.0.1; Xcode 27.1 or later and XcodeGen
Run itmake sim (simulator), make device (your iPhone)
Checkmake verify
Read moreQuick start, Architecture

beacon-firmware

Firmware and tools for the UWB beacons, Qorvo DWM3001CDK boards: uwbprobe, a test firmware of our own with no SDK; our patches to Qorvo's Nearby Interaction firmware and its build; scripts to identify, back up and flash a board; serial and Bluetooth tools. Qorvo's SDK is never in the repo.

Sourcegithub.com/save-the-world-org/beacon-firmware
Runs atA DWM3001CDK board, carried by the person to be found
Built withC (Apple's clang), probe-rs, Python's standard library, shell
Run itbrew bundle --file=Brewfile, scripts/identify, scripts/backup, make flash-uwbprobe
Checkmake verify
