Quick start

Four ways in: the glasses, the iPhone, the live map and an agent.

On Meta Ray-Ban Display

The glasses run Web Apps from an HTTPS address, so this works whether the paired phone is Android or iPhone.

  1. In the Meta AI app: Settings, App Info, tap the app version five times, then Enable (Developer Mode).
  2. App Settings, App connections, Add a Web App, with your own seeker id: 
    https://hero-goggles.darkshift.cloud/?seeker=<id>
    Without ?seeker=, Find uses the build's default seeker, phone.
  3. Open Hero Goggles from the glasses' apps. Swipe between the list, Map and Find; Back comes home.

Source: hero-goggles/README.md.

On the iPhone

hero-goggles-ios is released as source (v0.1.0): build it with Xcode 27.1 or later and XcodeGen.

git clone https://github.com/save-the-world-org/hero-goggles-ios.git
cd hero-goggles-ios
make sim                                # a simulator with Meta's simulated glasses
cp Config/Signing.example.xcconfig Config/Signing.local.xcconfig   # your Apple team
make device DEVICE=<identifier>        # from: xcrun devicectl list devices

In the app, Connect with Meta AI and Allow. The seek needs a beacon running Qorvo's Nearby Interaction firmware: see beacon-firmware/README.md, step 6, and flash with scripts/flash. The lens's direction arrow needs camera assistance and is not reported working yet; distance is.

The live map

Open hero-goggles.darkshift.cloud/live/ on a phone or a laptop. It shows the Salt Palace, every beacon with its last reading and estimated position, the seekers, the registry, each influencer's page, Find by voice, the alerts and the sponsors' integrations. Add ?seeker=<id> to follow one seeker.

No beacon to hand? scripts/fake-reading.sh <seeker> [distance] [azimuth] in hero-goggles posts a reading each second for 20 seconds (hero-goggles/scripts/fake-reading.sh).

MCP, for agents

influence-api serves MCP over streamable HTTP at /mcp. Add it to Claude Code:

claude mcp add --transport http influence https://influence-api.darkshift.cloud/mcp

Then ask it to "find Kunal". The tools: find_influencer, stop_finding, where_is, list_influencers, search, and, with the write key, register_influencer, register_beacon and map_beacon (influence-api/server.js). In a browser that offers navigator.modelContext, the live map hands an agent the same actions through WebMCP (hero-goggles/src/live/webmcp.js).

Run it yourself

# the API, http://localhost:8080
git clone https://github.com/save-the-world-org/influence-api.git && cd influence-api && npm start

# the web app, http://localhost:5173
git clone https://github.com/save-the-world-org/hero-goggles.git && cd hero-goggles && npm install && npm run dev

influence-api runs with no settings; everything stays in memory until ES_URL points at Elasticsearch.
